== Description ==

Update WordPress plugins and themes from private GitHub, GitLab, Gitea/Forgejo, or Bitbucket repositories. A JSON update feed is also supported for any other host that can serve version metadata.

== Installation ==

1. Copy this folder to `wp-content/plugins/private-repo-updater`.
2. Activate **Private Repo Updater**.
3. Open Settings → Private Repo Updates and add a source.
